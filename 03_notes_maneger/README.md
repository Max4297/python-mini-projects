# Notes Manager

A simple console-based notes manager written in Python.

## Features

- Add a new note
- Show all saved notes
- Clear all notes
- Exit the application
- Automatically creates `notes.txt` when needed

## How It Works

Notes are stored in a local `notes.txt` file.

The application provides a menu that allows the user to add, view, or clear notes.
